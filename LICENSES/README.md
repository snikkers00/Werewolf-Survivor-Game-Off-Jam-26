## Kenney assets
The project README credits [Kenney](https://kenney.nl/) for UI and 3D models.
`ui/Kenney Pixel.ttf` appears to be from
[Kenney Fonts](https://kenney.nl/assets/kenney-fonts), which is listed as CC0.
The [CC0 1.0 text](CC0-1.0.txt) is included here.
Identify the exact packs and files used, and verify their respective licenses
and any modifications; do not assume every UI, model, font, or sound file is
from Kenney.
## Character sprites
- The project README credits [Animated Pixel Adventurer by rvros](https://rvros.itch.io/animated-pixel-hero)
  for the human sprite. The `entities/sprites/adventurer-*.png` filenames
  suggest a connection, but the file mapping and modifications need
  confirmation. The source page permits use in personal and commercial
  projects and modifications, but says the asset may not be resold or
  redistributed. Confirm with the creator whether publishing these source
  files is permitted; credit alone does not grant redistribution rights.
- The project README credits [Free Werewolf Sprite Pixel Characters](https://free-game-assets.itch.io/free-werewolf-sprite-sheets-pixel-art)
  by Free Game Assets for the werewolf sprite. Confirm which repository files
  are from this pack, any modifications, and the applicable use and
  redistribution terms before publication.
